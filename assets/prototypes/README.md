# Hero prototypes

All cards are 1280×480, self-contained SVG. `assets/hero.svg` is a copy of B.

- `hero-a-terminal-twin.svg` - the first hero, kept for comparison: left wordmark and a right terminal window, the same layout as the Guide Me hero.
- `hero-b-sheet-csv.svg` - a dashboard-only worksheet (not a published view) slides out of a published dashboard and becomes a CSV file, so the picture itself says "any sheet, no workbook".
- `hero-c-typographic.svg` - an editorial poster where the oversized two-tone wordmark carries the card and a serif "Pull the sheet. Leave the workbook." sets the tone.
- `hero-d-pipeline.svg` - setup, add, and run as three colored stages on one track that ends in `exports/<job>/<sheet>.csv`.
- `hero-e-crosstab.svg` - the whole card is a Tableau-style highlight table for a dashboard-only "Order Detail" sheet, which is the exact thing tabpull exports.
